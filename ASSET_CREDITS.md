# Added asset credits

## Movie poster artwork

The new poster previews represent *The Matrix*, *Barbie*, *Coco*, *The Batman*, *La La Land*, and *RRR*. The images were sourced from movie-poster gallery/database pages and optimized into WebP files for the demo.

Movie poster artwork remains the property of its respective rights holders. These previews are included for this educational/demo movie-booking project. Confirm permissions or replace the artwork before commercial or broad public distribution.

## Fonts

- [Bebas Neue](https://fonts.google.com/specimen/Bebas+Neue) — Ryoichi Tsunekawa; used for condensed display headings.
- [Yellowtail](https://fonts.google.com/specimen/Yellowtail) — Astigmatic; used for handwritten script accents.

The font files are self-hosted so the site does not need a third-party font server at runtime. Keep the corresponding upstream font licenses with the font files when redistributing them.
